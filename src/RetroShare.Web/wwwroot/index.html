SHARE FILES LIKE IT'S 1995

A modern file-sharing platform with a retro soul: streaming uploads over gRPC, expiring password-protected share links, storage quotas, and a full role & permission engine — all wrapped in a CRT-inspired interface.

▶ STREAMED TRANSFERS

Files move over a gRPC data plane in 64 KB chunks — huge files never buffer in memory, and the UI shows live progress, speed and ETA.

⇄ SMART SHARING

Public links with expiration dates, optional passwords and download limits. Revoke anything, any time. Tokens are cryptographic, never sequential.

⚙ ROLES + PERMISSIONS

A real authorization engine: roles bundle database-stored permissions, policies check permissions — nothing is hard-coded to an "admin" string.
